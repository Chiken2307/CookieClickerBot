# Cookie Clicker Bot

A bot that plays cookie clicker for the steam version of the game, I do not want to make a version for the web version of the game so deal with it.


## Instuctions

I will be making a executable later on, but for now you will have to use some sort of IDE or anything that can run code.

1. Have OpenCV Installed, This is a must have because the whole programm hinges on looking at the screen and be able to look at images.
2. Have python and pip installed to latest version (DUH!).
3. Make sure you have pyautogui in your pip library, just look up how to download it.
4. Like Ive said you must have the steam version of Cookie clicker.
